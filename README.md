## About this repository

This is the source code for my personal portfolio, built with Next.js 16, Three.js, GSAP, and Lenis.

It features:

- **3 selected projects** representing my software engineering work (React, Node.js, Python, C++).
- **5 experience entries** mapping my educational and technical background.
- A WebGL/Three.js tunnel intro with GSAP scroll-driven cinematics.

## Local Development

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Architecture

- **Framework:** Next.js 16 (App Router), strictly typed with TypeScript.
- **Motion:** GSAP 3 (ScrollTrigger) & Lenis smooth scroll.
- **3D:** Three.js for the generative tunnel intro.
- **Styling:** Vanilla CSS modules, maintaining a strict design system without utility-class bloat.
